# LinkedIn Project Post

🚀 I’m excited to share my **AI-Based Job Tracker** — a full-stack project designed to make the job search process easier to organize and navigate.

Keeping track of applications while tailoring a resume to different roles can be challenging. This application brings those workflows together: users can manage job applications, upload a PDF resume, and compare it with a job description to receive an AI-powered analysis. Previous analysis results are also available to revisit.

**Highlights**
- Create and update job application records
- Analyze a resume against a specific role and job description
- Review and revisit previous resume analyses
- Use a responsive React interface

**Built with:** React, TypeScript, Vite, Node.js, Express, MongoDB, Redis, and OpenAI.

This project gave me the opportunity to work across a full-stack application—from building the user interface and API to connecting data storage and AI-powered analysis.

🔗 **Project repository:** https://github.com/Dushant-A-Banpurkar/AI-Based-Job-Tracker

I’d love to hear your feedback and suggestions!
